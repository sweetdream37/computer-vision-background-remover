# Умные ножницы — автоматическое удаление фона

## Итоговый проект по дисциплине «Компьютерное зрение 1»

**Вариант №7**

### Описание проекта

Программа предназначена для автоматического выделения объектов
на изображениях и удаления фона с использованием классических
методов компьютерного зрения.

Пользователь загружает фотографию, выделяет объект прямоугольником,
после чего программа автоматически отделяет объект от фона.

### Используемые технологии

- Python 3.9
- OpenCV
- NumPy
- PySide6
- Алгоритм GrabCut
- Gaussian Blur
- Морфологические операции
- Поиск контуров

### Возможности программы

1. Загрузка фотографий.
2. Выделение объекта мышкой.
3. Автоматическое удаление фона.
4. Построение бинарной маски.
5. Определение контуров объекта.
6. Сохранение изображения с прозрачным фоном.
7. Сохранение бинарной маски.
8. Измерение времени обработки.

### Установка

Установить необходимые библиотеки:

```bash
python3 -m pip install -r requirements.txt
```

### Запуск

```bash
python3 main.py
```

### Принцип работы

1. Пользователь загружает изображение.
2. Выделяет объект прямоугольником.
3. Алгоритм GrabCut выполняет сегментацию.
4. Полученная маска обрабатывается.
5. Программа определяет контуры.
6. Фон становится прозрачным.
7. Результат сохраняется в PNG.

### Ограничения

При сложном фоне и похожих цветах объекта и окружения
возможны неточности сегментации.
